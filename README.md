# Oruj Ismayilov Academic WordPress Theme

This repository contains a reusable WordPress block theme for the academic website of Oruj Ismayilov.

## Included

- `theme.json`
- `style.css`
- `functions.php`
- `parts/header.html`
- `parts/footer.html`
- `parts/sidebar-publication.html`
- `parts/sidebar-project.html`
- `templates/page.html`
- `templates/index.html`
- `templates/single-publication.html`
- `templates/single-project.html`
- `assets/oi-monogram.svg`

## Usage

1. Upload this theme folder to your WordPress installation under `wp-content/themes/`.
2. Activate the theme in Appearance → Themes.
3. Create `Primary` and `Footer` navigation menus in Appearance → Menus.
4. Assign the relevant pages to the blocks as needed.
5. For the publication detail page, use the `single-publication.html` template.

## Notes

- The theme is designed as a block theme and supports the WordPress Site Editor.
- The header and footer are reusable template parts.
- Styling is intentionally restrained and academic.
